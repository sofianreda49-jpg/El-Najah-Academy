# El Najah Academy — Frontend (React + Vite)

## التشغيل (والباك إند شغّال على بورت 8000)

```powershell
npm install
npm run dev
```

افتح http://localhost:5173

- في التطوير الطلبات `/api` بتتحوّل تلقائياً للباك إند (vite.config.js).
- في الإنتاج: لو الباك إند على دومين تاني، اعمل ملف `.env.production` فيه
  `VITE_API_URL=https://api.your-domain.com`
